# 油田ERP生产计划模块：搞懂PP模块核心概念

> 生产计划模块（PP）是整个ERP系统的"指挥官"，告诉油田每月产多少油、怎么产、需要什么资源。

---

## 一、PP模块是干什么的？

想象你是油田的**"生产指挥官"**，每个月初，上级会给你一个任务：这个月要产多少原油。

**PP模块就是你的指挥系统**——它帮你：
- 把年度大目标分解成月度小目标
- 把月度目标分解到每一口井
- 计算需要多少物资
- 安排什么时候做什么作业
- 跟踪实际完成情况，发现偏差及时调整

**一句话：PP让油田从"凭经验拍脑袋"变成"用数据做决策"。**

---

## 二、核心概念详解

### 1. 配产计划（Production Allocation Plan）

**上级单位根据各油田产能、资源状况、市场需求，下达给油田的产量任务。是PP模块的总输入。**

**举例**：集团公司给某油田下达2025年度配产100万吨，油田生产科据此分解：
- 老井自然产量70万吨
- 新井贡献20万吨
- 措施增油10万吨

---

### 2. 年度配产分解

**将年度总产量任务分解到12个月、每个采油厂、每口井。**

考虑季节性因素（如冬季稠油难采）、设备检修窗口、新井投产节奏等。

### 3. 作业计划（Operation Scheduling）

**安排具体的井下作业施工，包括修井、措施、注水注汽调整等。像排班表一样，明确哪口井、什么时间、做什么作业。**

**举例**：3月5日-10日，修井1队到杏2-1-斜23井进行检泵作业；3月8日-15日，压裂队到杏3-2-平17井压裂，预计日增油8吨。

### 4. MRP 物料需求计划 ⭐

**根据生产计划和作业计划，自动计算出需要什么物料、多少数量、什么时间到位。确保物资"不断供、不积压"。**

**MRP的"倒推"逻辑：**
- 不是"看看仓库还剩多少"
- 而是根据**作业计划时间 + 采购提前期 + 安全库存**倒推采购时间和数量

**举例**：3月5日需要用压裂液，供应商备货到送货需要7天，系统会在2月26日就发出采购提醒。

### 5. 能力评估（Capacity Evaluation）

**评估现有设备、人员、基础设施能否满足生产计划的要求。能力不足则需调整计划或扩容。**

**举例**：联合站设计处理能力5000吨/天，目前日产4800吨，还有余量200吨/天。但如果计划日产5500吨，就需要评估是否需要增加处理设施。

---

### 6. 产量波动分析 ⭐

**实际产量与计划产量出现偏差时，分析原因——是油井故障、措施效果不佳、原油含水上升，还是注水不足导致地层能量下降？**

**🔍 案例分析：1月份欠产3000吨的原因追踪**

| 分析维度 | 计划产量 | 实际产量 | 偏差 | 偏差原因 |
|---------|---------|---------|------|---------|
| **全油田合计** | 8.5万吨 | 8.2万吨 | -3000吨 | 欠产3.5% |
| 老井自然产量 | 6.5万吨 | 6.1万吨 | -4000吨 | 3口高产井结蜡严重，含水上升 |
| 新井贡献产量 | 1.2万吨 | 1.0万吨 | -2000吨 | 2口新井投产延期（压裂设备故障） |
| 措施增油 | 0.8万吨 | 1.1万吨 | +3000吨 | 注水调剖效果超预期，3口井增产明显 |

## 三、PP业务流程全貌

**从年度配产到日常作业调度，PP模块的完整业务流程：**

```
年度配产（集团下达100万吨任务）
→ 月度分解（1月8.5万、2月7.8万...）
→ 能力评估（设备、人力够不够）
→ MRP计算（管材、药剂要多少）
→ 作业调度（哪口井/什么时候/做什么）
→ 产量跟踪（实际vs计划，差异分析）
→ 调整优化（修补差异，滚动预测）
```

## 四、与其他模块的联动

| 联动对象 | 联动内容 | 油田示例 |
|---------|---------|---------|
| **PP → MM** | 作业计划触发物料需求 | PP计划压裂5口井 → MM自动生成压裂液、支撑剂采购申请 |
| **PP → PM** | 生产计划需要设备保障 | 日产5000吨走联合站 → 联合站设备不能在这个月安排大修 |
| **PP → QM** | 产量决定检验频次 | 外输5000吨/天 → QM每天取5个样品做全项分析 |
| **PP → EHS** | 高风险作业需安全审批 | 压裂作业前 → EHS审批HSE作业计划书，检查安全措施 |
| **PP → CO** | 产量归集到成本中心 | 每口井的产量对应成本中心，用于计算吨油操作成本 |

## 五、总结

| 概念 | 作用 |
|-----|------|
| 配产计划 | 上级下达的产量任务——PP的总输入 |
| 年度配产分解 | 将大目标分解到每月每井 |
| 作业计划 | 安排具体的井下作业——排班表 |
| MRP | 根据计划自动计算物料需求——不断供不积压 |
| 能力评估 | 评估能否满足计划——够不够 |
| 产量波动分析 | 找偏差原因——出了什么问题 |

**一句话记住PP模块：**

```
PP模块是油田的"生产指挥官"
从配产到调度，用数据指挥每一口井
年度目标分解到月、月度计划落实到井
MRP确保物资不断供、不积压
产量波动分析帮助及时发现问题、调整策略
```

掌握这些核心概念，就掌握了PP模块的精髓！
