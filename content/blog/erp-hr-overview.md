# 油田ERP人力资源模块：搞懂HR模块核心概念

> 人力资源模块（HR）是整个ERP系统的"人管家"，管好油田的每一个人——从招聘入职到退休离职，从考勤打卡到工资发放。

---

## 一、HR模块是干什么的？

油田是一个庞大的组织，从上到下有很多层级。HR模块用**组织架构**来表达这种层级关系，每个层级都是一个**组织单元**，就像一棵倒置的树。

**HR模块就是油田的"人管家"**——管好每一个员工的"生老病死"：入职、转正、调动、晋升、离职、退休，以及贯穿始终的工资发放。

**一句话：HR让油田的每一个人都"归位到位"，每一分钱都"发得明白"。**

---

## 二、核心概念详解

### 1. 组织架构（OO）⭐

**描述企业的组织结构和层级关系，包含三个核心概念：人事组织、组织单元、成本中心归属。**

**某油田组织架构层级示例**

| 层级 | 组织单元 | 说明 |
|-----|---------|------|
| 一级 | **某油气田公司** | 集团/分公司级别，最高层组织单元 |
| 二级 | ├─ **采油厂** | 具体的生产单位，独立成本考核 |
| 三级 | │ ├─ **第一作业区** | 介于厂和基层之间，管辖若干采油队 |
| 四级 | │ │ └─ **采油一队** | 最一线的生产组织 |
| 五级 | │ │ └─ **采油一班** | 基层班组，最小的组织单元 |

**成本中心归属**是组织架构最重要的功能：哪个部门的员工，人工成本就算到哪个部门。比如采油一队的员工，其人工成本会归集到"采油一队"这个成本中心，便于准确核算各部门的成本。

### 2. 油田用工形式

| 用工形式 | 特点 | HR系统处理 |
|---------|------|-----------|
| **正式工** | 与油田直接签订劳动合同 | 完整的人事主数据，正常薪酬核算 |
| **劳务派遣工** | 与派遣公司签合同，派遣到油田工作 | 派遣员工信息由派遣公司管理，油田记录用工信息 |
| **业务外包** | 整项工作外包给第三方公司 | 不作为油田员工管理，按服务费结算 |

### 4. 职务序列 ⭐

**技术、管理、技能三通道——员工可以走不同的发展通道，不必都去挤"当官"的独木桥。**

**三大职务序列对比**

| 序列 | 发展路径（由低到高） | 适用岗位 |
|-----|-------------------|---------|
| **技术序列** | 助理工程师 → 工程师 → 高级工程师 → 技术专家 → 首席专家 | 地质工程师、钻井工程师、采油工程师 |
| **管理序列** | 副科级 → 正科级 → 副处级 → 正处级 → 局级 | 副科长/科长、副处长/处长 |
| **技能序列** | 初级工 → 中级工 → 高级工 → 技师 → 高级技师 | 采油工、钻井工、维修工 |

**关键理解**：一个高级工程师（技术序列）的薪酬待遇可能等同于甚至高于正科级（管理序列），这就是"双通道"的意义——不一定要当领导才能涨工资。

### 6. 成本中心归属 ⭐

**每个员工在HR系统中都归属于一个成本中心，其人工成本（工资、社保等）自动计入该成本中心。当员工调动时，成本归属也随之变更。**

**举例：某员工从采油一队调到采油二队**

| 时间 | 组织归属 | 成本中心 | 薪酬发放 |
|-----|---------|---------|---------|
| 2025年1月-3月 | 采油一队 | 成本中心CC-1101（采油一队） | 工资从采油一队成本出 |
| 2025年4月1日 | **调动生效** — 人事主数据更新，成本中心变更 |
| 2025年4月起 | 采油二队 | 成本中心CC-1102（采油二队） | 工资从采油二队成本出 |

**成本影响**：调动后，该员工人工成本自动计入新的成本中心，采油一队的月度成本会减少，采油二队的月度成本会增加。如果该员工参与了PS项目，项目归属也可能同步调整。

### 7. 倒班制度 ⭐

**油田生产是24小时不间断的，一线员工通常实行倒班制。HR系统需要支持各种倒班制度的考勤计算。**

**常见倒班制度详解**

| 倒班制度 | 具体安排 | 典型场景 |
|---------|---------|---------|
| **四班三倒** | 4个班组轮换，每天3个班次（8小时/班）<br>早班0:00-8:00/白班8:00-16:00/中班16:00-24:00<br>轮换周期：上6天休2天 | 长庆油田采油队 |
| **三班两倒** | 3个班组轮换，每天2个班次（12小时/班）<br>白班8:00-20:00/夜班20:00-次日8:00<br>轮换周期：上20天休10天 | 新疆油田偏远作业区 |
| **上28休28** | 连续工作28天，然后集中休息28天<br>工作期间每天12小时，住在作业区 | 海洋油气平台 |

HR系统自动根据倒班安排计算：出勤天数、夜班次数、加班时数、野外津贴天数，作为薪酬核算的基础数据。

---

### 8. 特种作业证管理 ⭐

**油田是高危行业，员工需要持有多种特种作业证才能上岗。HR系统需要追踪这些证书的有效期，在到期前自动提醒复审。**

**常见特种作业证及到期提醒**

| 证书名称 | 适用岗位 | 有效期 | HR系统提醒 |
|---------|---------|-------|-----------|
| **井控证** | 钻井工、井下作业工 | 4年 | 到期前3个月提醒复审 |
| **注汽证** | 注汽锅炉操作工 | 4年 | 到期前3个月提醒复审 |
| **压力容器证** | 联合站操作工 | 4年 | 到期前3个月提醒复审 |
| **电工证** | 维修电工 | 6年（每3年复审） | 到期前3个月提醒复审 |
| **焊工证** | 维修焊工 | 6年（每3年复审） | 到期前3个月提醒复审 |

**安全底线**：证书过期未复审，员工不能上岗。HR系统的自动提醒功能直接关系到生产安全和合规运营。

## 三、核心业务场景

### 场景一：钻井队月度工资核算完整流程

**第一步：收集考勤数据**
- 从考勤系统获取本月每个人的出勤天数
- 如有请假，调出请假单据；如有加班，记录加班时数

**第二步：计算产量奖金**
- 根据钻井队本月完成的钻井进尺，按照既定奖金单价计算奖金总额，分配到每个人

**第三步：安全考核**
- 根据本队本月安全表现计算安全奖或安全扣罚

**第四步：计算应发工资**
```
应发工资 = 岗位工资 + 绩效工资 + 津补贴 + 产量奖金 + 安全奖 + 加班费 - 考勤扣款
```

**第五步：代扣代缴**
```
实发工资 = 应发工资 - 五险一金个人部分 - 个人所得税 - 其他扣款
```

**第六步：成本归集**
- 通过HR-PS集成，工资中的项目人员部分自动归集到对应PS项目
- 通过HR-CO集成，人工成本归集到对应成本中心
- 通过HR-FI集成，生成工资发放的财务凭证

---

### 场景二：员工调动——动一动不容易

员工在油田内部调动，涉及多个HR操作：

- **调出操作**：发起调动申请 → 办理工作交接 → 更新人事主数据中的组织归属 → 更新成本中心归属
- **调入操作**：接收调动申请 → 确认接收 → 更新薪酬归属
- **成本影响**：调动后，该员工的人工成本自动计入新的成本中心；如果参与PS项目，项目归属也可能调整

---

### 场景三：绩效管理——考核的"指挥棒"

| 岗位类型 | 考核指标示例 | 考核周期 |
|---------|------------|---------|
| 采油工 | 产量指标、安全指标、设备完好率 | 季度+年度 |
| 地质工程师 | 储量任务、方案编制质量、技术创新 | 季度+年度 |
| 管理干部 | 安全环保、产量任务、队伍稳定、廉洁自律 | 季度+年度 |

考核结果分为：优秀、良好、称职、基本称职、不称职，与薪酬、晋升直接挂钩。

## 四、与其他模块的关系

| 模块关系 | 数据流向 | 关键集成点 |
|---------|---------|-----------|
| **HR → FI** | HR向FI传递薪酬数据 | 工资发放生成付款凭证，代扣代缴生成应交税金凭证 |
| **HR → CO** | HR向CO传递人工成本 | 人工成本归集到成本中心，支持成本分析 |
| **HR → PS** | HR为PS提供项目人员成本 | 项目人员工资自动从HR模块获取并计入PS项目 |
| **HR → PP** | HR向PP传递工时数据 | 倒班工时用于生产计划排产 |

## 五、油田特色业务

### 5.1 有毒有害工种补贴

油田一些岗位接触有毒有害物质，按规定需要发放**有毒有害工种补贴**：

- **接触硫化氢岗位**：油气开采中可能遇到硫化氢
- **放射线岗位**：测井、射线探伤等
- **粉尘岗位**：固井、压裂等作业
- **噪声岗位**：钻井、井下作业等

HR系统需要维护有毒有害岗位清单，根据员工实际从事岗位计算补贴，并定期组织职业健康检查。

### 5.2 野外作业津贴

油田工作地点往往在荒郊野外，远离城镇。津贴标准与作业地点（荒漠、沙漠、海上等）、作业期限、生活条件艰苦程度相关。HR系统根据员工的实际作业安排，自动计算野外作业津贴。

### 5.3 职工家属劳保

这是油田企业的特色福利：正式职工的**直系家属**可以享受一定的劳保待遇，包括劳动保险参保、医疗费报销（部分）、困难补助。HR系统维护职工家属信息，并在福利计算时予以考虑。
