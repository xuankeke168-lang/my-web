# 油田ERP设备管理模块：搞懂PM模块核心概念

> 设备管理模块（PM）是整个ERP系统的"保健医生"，让每一台设备保持健康运转。

---

## 一、PM模块是干什么的？

想象一下，油田就像一个有几千个"孩子"的大家庭——**每台设备都是一个需要照顾的"孩子"**。

磕头机每天24小时不停地"磕头"、压缩机日夜不停地运转、输油泵24小时不间断送油……

**PM模块就是这些设备的"私人保健医生"**——定期体检、生病开药、记录病历、结算费用，全部管起来！

---

## 二、核心概念详解

### 1. 功能位置（Functional Location）

**设备的"家庭住址"——描述设备安装在哪个位置。**

功能位置是描述设备安装在哪个位置的结构化地址，就像家庭住址——省、市、区、街道、门牌号。它不是描述设备本身，而是描述设备**"待的地方"**。

**地址结构（层级编码）：**

| 级别 | 内容 | 示例 |
|-----|------|------|
| 第1级 | 区域/油田 | A联合站区域 |
| 第2级 | 场站/装置区 | 2号装置区 |
| 第3级 | 设备位号 | 3号输油泵 |
| 第4级（可选） | 子设备位 | 电机、轴承座 |

**编码示例：** `ALS-02-PUMP-003`
- ALS = A联合站
- 02 = 2号装置区
- PUMP = 泵类设备
- 003 = 第3台设备

**为什么需要功能位置？**

- 设备可能会移动，但功能位置不变
- 维修人员像用导航一样，根据功能位置精准找到设备
- 与成本中心关联：这个位置上的维修费，自动归集到对应的成本中心

---

### 2. 设备主数据（Equipment Master）

**设备的"完整档案"——身份证+病历本+体检报告的合体。**

每台重要设备在系统里记录从"出生"到"退休"的全部信息。

**设备主数据包含内容：**

| 信息类别 | 具体内容 | 用途 |
|---------|---------|------|
| 基本信息 | 设备编号、名称、型号、制造商、出厂日期 | 识别设备"是谁" |
| 技术参数 | 功率、转速、压力等级、温度范围、额定产量 | 知道设备"能干什么" |
| 位置信息 | 所属功能位置、所属成本中心、安装日期 | 知道设备"在哪儿" |
| 维修历史 | 历次维修记录、故障现象、更换配件清单 | 知道设备"得过什么病" |
| 备件清单 | 常用维修备件型号、数量、供应商 | 方便维修时快速领料 |
| 运行统计 | 累计运行小时数、启停次数、产量累计 | 判断设备"累不累" |

**举例：某磕头机（抽油机）的完整档案**

```
设备编号：S-01（磕头机1号）
型号：CYJ10-3-53HB（最大载荷10吨、冲程3米）
制造商：胜利油田高原石油装备公司
出厂日期：2018年3月15日
启用日期：2018年5月20日
功能位置：A采油区-1号计量站-S-01
所属成本中心：A采油队成本中心
累计运行小时：48,500小时

维修历史速览：
2020-03：换曲柄销子（运行12000小时）
2021-06：换电机轴承（运行21000小时）
2022-09：游梁平衡调整（运行32000小时）
2023-12：整机大保养（运行45000小时）
2024-06：换减速器润滑油（运行48500小时）
```

### 3. 维修策略（Maintenance Strategy）

**预防为主的"保养计划表"——规定设备"什么时候该保养、做什么项目"。**

**四种维修策略对比：**

| 策略类型 | 触发条件 | 适用场景 | 优点 | 缺点 |
|---------|---------|---------|------|------|
| 时间基准策略 | 按日历时间 | 磕头机、输油泵等连续运行设备 | 计划性强 | 可能与实际磨损不同步 |
| 运行基准策略 | 按运行小时数 | 压缩机、发电机、车辆 | 与实际使用量挂钩 | 需要准确计量运行数据 |
| 性能基准策略 | 按产出量 | 大量产出型设备 | 与产出效益绑定 | 产量波动大时难规划 |
| 状态基准策略 | 按设备实时状态 | 关键高价值设备 | 精准，不过度保养 | 需要传感器和监测系统 |

**对比理解：**
- 时间基准 = 每年体检一次，不管你身体好不好
- 性能基准 = 手环实时监测心率，心率一异常立刻去医院

---

### 4. 预防性维护（Preventive Maintenance）

**自动生成的"保养课程表"——根据维修策略，系统自动生成未来的保养任务计划。**

**预防性维护如何工作？**

```
设定维修策略（参数：周期、项目）
→ 系统计算下次到期日（根据日历/运行小时）
→ 自动生成保养计划（按月/周列出任务）
→ 到期前提醒（通知维修班长）
→ 自动生成工单（派发执行）
```

**举例：50台磕头机的预防性维护**

```
策略配置：
• 一级保养（换润滑油、紧固螺栓）：每月1次
• 二级保养（全面检查、调整间隙）：每季度1次
• 大保养（整机检修）：每运行8000小时

系统自动运行：
每月25号，系统自动生成下月保养计划：
— 12月1日：S-01~S-10 一级保养
— 12月2日：S-11~S-20 一级保养
— 12月3日：S-21~S-30 一级保养
```

**关键理念：治未病**——在设备出问题之前就进行保养，避免故障停机。

---

### 5. 工单（Work Order）

**维修任务的"派工单"——每一张工单记录了：修什么设备、谁来修、什么时候修、用了什么备件、花了多少钱。**

**三大工单类型对比：**

| 对比维度 | 🟢 计划保养工单 | 🔴 紧急抢修工单 | 🟡 改造工单 |
|---------|---------------|----------------|-------------|
| 触发方式 | 系统根据预防性维护自动生成 | 设备突发故障，人工创建 | 设备升级/改造项目，人工创建 |
| 紧急程度 | 低——按计划执行即可 | 高——可能影响产量/安全 | 低——按项目计划执行 |
| 审批流程 | 班长直接派发 | 主管领导快速审批 | 需立项/预算审批 |
| 备件准备 | 提前准备，库存充足 | 紧急领用/加急采购 | 专项采购，纳入项目预算 |
| 成本归属 | 维护修理费-计划保养 | 维护修理费-紧急抢修 | 设备改造/资本化 |

**工单编号规则：**
- `PM-2024-1205-S01` = 计划保养 + 2024年 + 12月05日 + S01设备
- `EM-2024-0115-URG` = 紧急抢修 + 2024年 + 01月15日 + URGENT

---

### 6. 维修成本归集

**每一分维修费都"有账可查"——工单关闭后，系统自动把维修产生的各项费用归集到对应的成本中心。**

**成本归集的三条路径：**

| 路径 | 说明 |
|-----|------|
| 备件费用 | 工单中领用的备件 → 通过MM模块从仓库扣减 → 成本自动计入工单 |
| 人工费用 | 维修人员填写的工时 → 乘以小时费率 → 成本计入工单 |
| 外委费用 | 外部维修队伍的发票 → 录入系统 → 成本计入工单 |

**成本归集流向图：**

```
备件领用 → 工单成本汇总（备件+人工+外委）→ 成本中心 → 财务凭证
（从仓库领轴承1套）                        （联合站成本中心）  （FI自动记账）
```

**举例：工单完成后成本自动归集**

场景：2号联合站1号外输泵紧急抢修

| 成本要素 | 金额 | 来源 |
|---------|------|------|
| 备件费 - 轴承 | 800元 | MM仓库领用 |
| 人工费 - 维修工时 | 360元（2人×3小时×60元/小时） | 工时确认 |
| 外委费 - 加急运费 | 500元 | 外部服务 |
| **合计** | **1,660元** | |

系统自动归集到："联合站成本中心" → "维护修理费-紧急抢修"科目

**财务凭证自动生成：**
```
借：联合站成本中心-维护修理费    1,660元
贷：原材料-轴承                       800元
贷：应付职工薪酬                       360元
贷：应付账款-供应商                    500元
```

整个过程，**财务人员不需要手工做任何一笔分录**！

## 三、四大业务流程

### 流程一：磕头机定期保养

**标准保养周期：**

| 保养级别 | 周期 | 主要工作内容 | 预计工时 |
|---------|------|-------------|---------|
| 日常巡检 | 每天1-2次 | 目视检查、听异响、摸温度 | 0.5小时/次 |
| 一级保养 | 每月1次 | 紧固螺栓、检查润滑、更换小件 | 2-3小时/台 |
| 二级保养 | 每季度1次 | 全面检查、调整间隙、更换磨损件 | 4-6小时/台 |
| 大保养 | 每年/每8000小时 | 整机检修、油漆防腐、更换主要配件 | 8-12小时/台 |

**流程步骤：**
```
计划生成 → 任务派发 → 执行保养 → 系统确认
（系统根据策略自动生成） （维修班长分配） （现场作业，填写保养记录） （确认完成，记录备件和工时）
```

---

### 流程二：应急抢修

**流程步骤：**
```
故障报警 → 紧急工单 → 快速抢修 → 事后补录
（电话报告+启动应急） （创建"紧急"标签工单） （先恢复运行） （补录工单内容和成本）
```

**紧急抢修 vs 计划保养的关键区别：**
- **紧急抢修**："先救人、后办手续"——设备先修好恢复生产，手续可以后续补
- **计划保养**："先挂号、再看病"——按计划好的时间和内容执行

好的PM管理追求的是"紧急工单越来越少，计划保养有序执行"。

---

### 流程三：故障维修（非紧急）

**流程步骤：**
```
故障发现 → 故障报告 → 故障诊断 → 维修执行 → 工单关闭
（巡检或监控报警） （创建故障工单） （确定原因和方案） （领备件、施工） （确认完成，归集成本）
```

---

### 流程四：设备大修

**流程步骤：**
```
立项审批 → 准备工作 → 施工执行 → 验收试运行 → 工单结算
（申报大修项目） （备件采购、施工方案） （拆解、维修、更换） （性能测试） （归集全部成本）
```

## 四、油田特色业务

### 设备与成本中心关联

设备归属于哪个成本中心，维修成本就记到哪个成本中心。这是**油田成本核算的基石**。

| 设备类型 | 典型设备 | 所属成本中心 | 维修成本科目 |
|---------|---------|------------|-------------|
| 采油设备 | 磕头机、井下泵、螺杆泵 | 采油队成本中心 | 采油生产成本-维护修理费 |
| 联合站设备 | 脱水泵、加热炉、三相分离器 | 联合站成本中心 | 油气处理成本-维护修理费 |
| 注水设备 | 注水泵、注水阀组、增压泵 | 注水站成本中心 | 注注水成本-维护修理费 |
| 集输设备 | 外输泵、计量撬、管道阀门 | 集输大队成本中心 | 集输成本-维护修理费 |
| 公用设备 | 办公楼空调、公务车、后勤设备 | 后勤成本中心 | 管理费用-维护修理费 |

---

### 特种设备管理

锅炉、压力容器、起重机械等属于**特种设备**，受国家《特种设备安全法》管理。

**管理要点：**
- **注册登记**：特种设备必须注册登记，取得使用登记证
- **定期检验**：每年由特种设备检验研究院强制检验
- **持证上岗**：操作人员需持有《特种设备作业人员证》
- **安全档案**：建立安全技术档案，保存设计文件、检验报告、运行记录
- **到期预警**：系统设置检验日期预警，提前30天提醒报检
- **停用管理**：检验不合格自动锁定，禁止使用

---

### 井下工具管理

封隔器、桥塞、射孔枪等**"一次性"或"限次使用"**的井下工具，对安全性和追溯性要求极高。

**管理流程：**
```
入库验收（检验+登记唯一编号）
→ 库存管理（分类存放+防锈处理）
→ 出库使用（关联井号+记录深度）
→ 回收/报废（可回收检验入库，不合格报废）
```

## 六、总结

| 概念 | 作用 |
|-----|------|
| 功能位置 | 设备的"家庭住址"——告诉你在哪里 |
| 设备主数据 | 设备的"完整档案"——身份+病历+体检 |
| 维修策略 | 预防为主的"保养计划表" |
| 预防性维护 | 自动生成的"保养课程表" |
| 工单 | 维修任务的"派工单" |
| 维修成本归集 | 每一分维修费都"有账可查" |

**一句话记住PM模块：**

```
PM模块是油田设备的"全生命周期管理医生"
功能位置告诉你设备在哪里
设备主数据记录设备的"身份和病历"
维修策略+预防性维护让设备"治未病"
工单是维修任务的执行载体
成本归集让每一分维修费都有账可查

好的PM管理追求的不是"修得快"，而是"少修甚至不修"
让设备健康运转，就是最好的降本增效。
```

掌握这些核心概念，就掌握了PM模块的精髓！
