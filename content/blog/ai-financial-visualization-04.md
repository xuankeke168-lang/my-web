**老板看完报表，问了3个字："然后呢？"**

财务经理愣住了。

他花了3天做了40页PPT，展示了收入、成本、利润、同比、环比——老板看完，说"挺好"，然后问"然后呢"。

然后呢？然后没有然后了。

这就是财务分析的死亡节点：**你看见了数据，但你没看见决策。**

财务分析有4个段位，每个段位问的问题不一样，能给的答案也不一样。

大多数财务在段位1，少数在段位2，能到段位3的是稀有物种。

---

## 财务分析的4个段位

### 段位1：数据呈现

**问题**："上个月发生了什么？"
**回答**：收入1234万，成本987万，利润247万。同比增长12%。

财务在这里停留太久的原因：这是最舒服的区段。做表，看数，交差。不用动脑子。

**卡点**：老板听完"上个月"，问"为什么会这样"——答不上来。

---

### 段位2：数据分析

**问题**："为什么会这样？"
**回答**：利润增长12%主要因为油价上涨贡献了8%，产量增加贡献了4%。但单位成本也上升了3%，因为材料价格上涨。

从段位1到段位2，需要一个能力：**拆解**。

把"利润增长"拆成"收入增长贡献"+"成本变化贡献"+"结构变化贡献"。

这个能力，靠Excel够用，靠Power BI更高效。但核心不是工具，是思路。

**拆解方法**：

```
利润变化 = 收入变化 - 成本变化
收入变化 = 销量变化贡献 + 价格变化贡献
成本变化 = 用量变化贡献 + 单价变化贡献

代入数字：
利润+12% = 收入+15% - 成本+8%
          = (销量+10% × 均价) + (油价+5%) - (材料+8% + 用量-2%)
```

这个拆解做出来，老板就知道"主要矛盾是什么"。而不是扔给他40页PPT，他自己找答案。

---

### 段位3：问题诊断

**问题**："问题出在哪里？"
**回答**：问题不在整体，在结构。子公司B贡献了收入增长的80%，但子公司A的成本超支了120万，拖累了整体利润。

从段位2到段位3，需要一个能力：**归因**。

拆解是回答"为什么变化"。归因是回答"哪个局部拖了后腿"。

**归因方法**：

```
不是"成本上升了"
而是"哪个部门、哪个产品、哪个时间段的成本上升了"

→ 成本+8%，其中：
  - 子公司A超支120万（材料浪费）
  - 子公司B超支30万（油价上涨，正常）
  - 子公司C节约20万（管理得当）

结论：子公司A需要重点关注
```

归因做出来，管理动作才能出来。不是告诉老板"成本上升了"，是告诉他"哪口井、哪个队、哪个项目出了问题，要处理谁"。

---

### 段位4：预测决策

**问题**："接下来怎么办？"
**回答**：按目前油价和产量预测，下个月利润会下降15%。建议本月底加速回款，同时和供应商谈材料账期延长30天，预估能释放500万现金流。

从段位3到段位4，需要一个能力：**预测**。

不是预测数字，是预测趋势，然后给建议。

**预测方法**：

```
第一步：确定驱动因子
  - 油价（影响收入50%）
  - 产量（影响收入30%）
  - 材料成本（影响成本40%）

第二步：设定情景
  - 乐观：油价+10%，产量持平，成本+5%
  - 基准：油价持平，产量-3%，成本+8%
  - 悲观：油价-20%，产量-8%，成本+15%

第三步：输出建议
  - 情景A下：利润1.2亿，正常
  - 情景B下：利润8000万，需要控制成本
  - 情景C下：利润3000万，需要融资准备

建议：
  1. 月底前回款加速（预计回笼800万）
  2. 和供应商谈30天账期（预计释放300万）
  3. 预留银行授信额度（备用500万）
```

这就是段位4的价值：你不是给老板看数字，你是帮老板做决策。

## 段位提升路径：3个关键能力

### 能力1：拆解能力（青铜→白银）

**怎么练**：

每个财务指标变化，都用"贡献度"拆解。

模板：

```
指标变化 = 因素A贡献 + 因素B贡献 + 因素C贡献

例：收入变化 = 销量贡献 + 价格贡献
     = (销量变化 × 上期价格) + (价格变化 × 本期销量)

验证：各因素贡献之和 = 总体变化（误差<1%即可）
```

练习材料：用你们上个月的财务报表，做一遍拆解。看看"收入增长15%"里，哪个产品、哪个区域、哪个客户贡献了多少。

---

### 能力2：归因能力（白银→黄金）

**怎么练**：

每次看到异常数据，问3个问题：

```
问题1：异常在哪里？（哪个部门/产品/时间段）
问题2：是真实异常还是口径问题？（先排查数据质量）
问题3：为什么会出现这个异常？（找根本原因，不是找直接原因）

例：
直接原因：运输费用超标
根本原因：井队搬迁频次增加（因为新井投产密集，配套运输能力没跟上）
```

不是所有异常都需要处理，但所有异常都需要知道原因。

---

### 能力3：预测能力（黄金→王者）

**怎么练**：

从下个月开始，做3个情景预测：

```
情景1：基准情景（最可能发生）
情景2：乐观情景（比基准好20%）
情景3：悲观情景（比基准差20%）

每个情景输出：
- 收入/成本/利润预测
- 主要风险点
- 应对建议
```

每月更新，每季度复盘准确率。

预测不准是正常的，没人能100%准确。重要的是**你有一套预测逻辑**，而不是"拍脑袋"。
