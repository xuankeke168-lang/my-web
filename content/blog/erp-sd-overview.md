# 油田ERP销售分销模块：搞懂SD模块核心概念

> 销售分销模块（SD）是整个ERP系统的"钱袋子"，从井口到炼厂，掌管油田每一笔收入的数字化管理。

---

## 一、SD模块是干什么的？

如果说ERP是油田的"数字神经系统"，那么**SD模块就是这个神经系统的"钱袋子"**。

**SD模块管四件事：**
- **接单**：从客户那里拿到销售订单
- **发货**：确保货物按时按量发出
- **开票**：向客户收取款项
- **收钱**：管理应收账款，确保资金回笼

**和其他模块的关系：**
- SD销售出库 → FI自动生成应收凭证
- SD销售确认收入 → CO自动归集销售成本
- SD交货过账 → MM自动扣减库存
- SD质量检验 → QM自动判定是否合格

---

## 二、核心概念详解

### 1. 销售范围（Sales Area）

**销售业务的"管辖地盘"——销售组织 + 分销渠道 + 部门。**

就像一个大型商场有不同的楼层、不同的柜台、不同的商品区——销售范围界定了企业销售业务开展的"三维空间"。

| 维度 | 说明 | 油田例子 |
|-----|------|---------|
| 销售组织 | 销售团队的"归属"，谁在卖 | 西北销售部、东部销售部 |
| 分销渠道 | 产品流向的"通道"，怎么卖 | 直销、经销、管道、公路 |
| 部门（产品组） | 产品线的"分类"，卖什么 | 原油部、天然气部、化工产品部 |

**举例**：长庆油田的销售范围拆分：
- 西安销售处 + 管道直销 + 天然气部 → 负责向城市燃气公司供气
- 银川销售处 + 公路经销 + 原油部 → 负责向地方炼厂供油

---

### 2. 销售订单（Sales Order）⭐

**客户想买什么的"需求单"——事务代码VA01。**

就像餐厅的点菜单——客户告诉你想点什么菜（产品）、要多少量（数量）、什么时间要（交期）。销售订单是整个销售流程的起点。

**核心信息：**
- 客户名称和地址
- 产品名称和规格
- 订购数量和单价
- 交货日期和地点
- 付款条件和信用额度

**举例**：新疆广汇炼厂在ERP中下达销售订单：
- 订购原油5000吨
- 单价参考上月国际油价+升贴水
- 交货日期3月15日
- 管道输送至克拉玛依炼厂进站口

系统自动执行：①信用额度检查 ②库存可用性检查 ③定价过程自动计算

---

### 3. 外向交货（Outbound Delivery）

**货物出门的"放行条"——事务代码VL01N。**

就像小区门口的出门条——货物要离开仓库必须要有"放行条"。外向交货单就是仓库确认"这批货可以出了"的凭证，同时触发库存扣减。

**重要作用：**
- 确认库存可用性
- 生成发货通知
- 触发库存扣减
- 记录实际发货数量（作为结算依据）

**原油管输外输流程：**
```
根据销售订单创建外向交货单VL01N
→ 管道站场启动输油泵
→ 流量计开始计量（初始读数1000.000吨）
→ 输油完成（最终读数6000.000吨）
→ 双方计量员签字确认实发5000吨
→ 过账发货VL02N
→ 系统自动扣减原油库存5000吨
```

---

### 4. 发票（Billing）

**收钱的"催款单"——事务代码VF01。**

就像餐厅吃完饭后服务员给你的账单——发票是向客户收钱的正式凭证，也是财务记账的法律依据。发票过账的那一刻，企业就确认了"这笔钱是我的了"。

**发票类型：**
| 类型 | 适用客户 | 可抵扣 |
|-----|---------|-------|
| 增值税专用发票 | 一般纳税人客户 | 是 |
| 增值税普通发票 | 小规模纳税人 | 否 |
| 电子发票 | 所有客户 | 按类型 |

**开具发票瞬间：**
```
借：应收账款    2373万
贷：主营业务收入    2100万
贷：应交税费-销项税  273万
```

---

### 5. 信用额度（Credit Limit）

**客户能欠多少钱的"透支上限"——事务代码FD32。**

就像信用卡有透支上限——银行不会让你无限制地欠钱。信用额度就是企业允许客户"先货后款"的最大欠款金额。

**控制逻辑：**
- 可用额度 = 信用总额度 - 已占用额度
- 订单金额 ≤ 可用额度 → 正常接单
- 订单金额 > 可用额度 → 系统警告或阻止

**举例**：某地方炼厂信用额度1000万，当前已交货未结算800万，可用额度=200万。现在炼厂又下了一个500万的订单 → 500万 > 200万 → 信用超限！系统弹出警告，订单被冻结。

---

### 6. 定价过程（Pricing Procedure）

**价格计算的"流水线"——系统自动执行6步计算。**

| 步骤 | 内容 |
|-----|------|
| ① | 读取基准价格（定价主数据） |
| ② | 应用数量折扣 |
| ③ | 应用付款条件折扣 |
| ④ | 加上运费、附加费 |
| ⑤ | 计算税额 |
| ⑥ | 得出含税总价 |

**举例**：客户购买原油1000吨的定价过程：

| 步骤 | 计算 | 结果 |
|-----|------|------|
| 基准价 | 4000元/吨 | 4000 |
| 数量折扣 | -50元/吨 | 3950 |
| 付款奖励 | -30元/吨 | 3920 |
| 运费附加 | +80元/吨 | 4000 |
| 增值税13% | 4000 × 13% | 520 |
| **含税总价** | **4000 + 520** | **4520元/吨** |

---

### 7. 收入确认时点（Revenue Recognition）

**什么时候算"赚到这笔钱"。**

| 确认方式 | 适用场景 | 说明 |
|---------|---------|------|
| 发货确认 | 管道原油 | 出厂站流量计读数即视为交货完成 |
| 签收确认 | 槽车液化气 | 客户在地磅签字确认后算确认 |
| 验收确认 | 特殊化工产品 | 化验合格签字后才确认收入 |

---

### 8. 关联交易（Intercompany Transaction）

**集团内部交易，定价要合规。**

中石油集团内部：长庆油田（采油）→ 宁夏石化（炼油）→ 西北化工（化工产品）。每一步都是关联交易，价格必须参照国际市场价或第三方评估价（独立交易原则）。

---

### 9. 国际油价挂钩定价（Brent-Linked Pricing）

**原油卖多少钱，国际油价说了算。**

**定价公式要素：**
| 要素 | 说明 | 示例 |
|-----|------|------|
| 基准价 | Brent/WTI原油价格 | 82美元/桶 |
| 品质升贴水 | 因密度、含硫量差异 | -0.8美元/桶 |
| 计价期 | 参考哪段时间的均价 | 上月26日至本月25日 |
| 汇率 | 美元转人民币 | 7.2 |
| 计量换算 | 桶转吨 | 1吨≈7.3桶 |

**计算示例：**

| 步骤 | 计算 | 结果 |
|-----|------|------|
| 调整后价格 | 82 - 0.8 | 81.2美元/桶 |
| 人民币价格 | 81.2 × 7.2 | 584.64元/桶 |
| 吨价 | 584.64 × 7.3 | 4268元/吨 |
| 含税价（13%） | 4268 × 1.13 | **4823元/吨** |

## 四、销售收款流程

| 步骤 | 操作 | 说明 |
|-----|------|------|
| 1 | 创建销售订单VA01 | 客户需求录入系统 |
| 2 | 创建外向交货VL01N | 检查库存可用性 |
| 3 | 过账发货VL02N | 库存扣减，生成物料凭证 |
| 4 | 开具发票VF01 | 生成应收凭证，确认收入 |
| 5 | 客户付款 | 收款录入F-28 |
| 6 | 清账核销 | 应收账款减少 |

## 五、SD和FI的区别

| 对比项 | SD销售分销 | FI财务会计 |
|-------|-----------|-----------|
| **职责** | 卖货（订单、发货、开票） | 记账（凭证、收款、报表） |
| **关注点** | 卖了多少、钱什么时候收 | 记了多少、账是否平衡 |
| **核心操作** | VA01、VL01N、VF01 | F-28、F-30 |
| **报表** | 销售业绩、回款分析 | 资产负债表、利润表 |

**记住一句话**：SD管"卖"，FI管"记"，两者紧密集成。

## 六、模块集成关系

| 集成关系 | 说明 |
|---------|------|
| SD → FI | 发票过账自动生成AR应收凭证和收入凭证 |
| SD → MM | 外向交货过账自动扣减库存 |
| SD → CO | 销售成本归集到成本中心，支持利润分析 |
| SD → QM | 交货前必须完成质量检验，合格才放行 |

**集成全景图：**

```
CO成本控制 ←→ SD销售分销 ←→ MM物料管理
                    ↑
                    ↓
            FI财务会计 ←→ QM质量管理
```
