# 什么是 Claude Code · 小白版

> 2026.06.13 · 工具 · 财务老登学 AI #003

---

如果你最近听人提"Claude Code"，但不知道是干啥的——

**别慌。**

我第一次听说它的时候，第一反应也是"又是啥新工具，跟 ChatGPT 啥区别"。

这篇，**就是给跟我一样的小白写的**：
- 没听过 AI 编程的
- 听到"命令行"三个字就头大
- 想搞懂这玩意儿到底能不能帮自己干活

看完这篇，你至少能**跟人聊起来不露怯**。

## 一、先说结论：Claude Code 是啥

**一句话**：Claude Code 是 Anthropic 公司出的一款**"能直接在你电脑上干活"的 AI 助手**。

听不懂？我拆成 3 个词：

- **Claude**：Anthropic 公司最厉害的 AI 模型（ChatGPT 的最大对手）
- **Code**：虽然叫 Code，但**不只是写代码**——能改文件、跑命令、查资料
- **终端 App**：装在你的电脑里，**直接操作你电脑的文件和软件**

跟 ChatGPT 的最大区别：

| 维度 | ChatGPT | Claude Code |
|---|---|---|
| 跑在哪 | 网页 / APP | **你电脑的终端** |
| 干啥的 | 回答问题 | **真干活**（改文件 / 跑命令 / 查代码） |
| 谁能用 | 任何人 | **会点命令行** |
| 价格 | 免费 / Plus $20/月 | **Pro $20/月** |

**关键差异**：ChatGPT 是"嘴上说"，Claude Code 是"动手做"。

## 二、举 2 个真实场景（财务老登视角）

### 场景 1：清洗 1000 行 Excel 数据

**没有 Claude Code 之前**：

我每个月要把 SAP 导出的 Excel 数据做清洗——
- 删空行
- 改日期格式
- 合并相同字段
- 补缺失的部门

这活儿我以前**手动搞 2 小时**。

**用 Claude Code 之后**：

我跟它说"帮我把当前文件夹的 `sales_2026q1.xlsx` 处理一下，删空行、日期改 YYYY-MM-DD、补部门"——

**3 分钟搞定**。

它会：
1. 自己看 Excel
2. 自己写 Python 脚本
3. 自己跑脚本
4. 自己检查结果
5. 出错了自己重试

我全程**就看了一眼**。

### 场景 2：写周报

**没有 Claude Code 之前**：
- 打开飞书文档
- 翻 5 个 Excel 找数据
- 拼成 800 字周报
- **40 分钟**

**用 Claude Code 之后**：
- `cd ~/weekly-reports`（切到周报文件夹）
- `claude "写本周财务周报，参考 templates/weekly.md"`（告诉它写啥）
- 它读模板 + 读上周数据 + 自己写
- 我**改 5 分钟**

**每周省 35 分钟，一年 30 小时。**

## 三、它适合谁 / 不适合谁

### ✅ 适合

- 财务老登（我）—— 不想学 Python 但想自动化
- 产品经理 —— 经常处理数据 / 文档
- 运营 —— 重复性工作多
- 任何 **"知道有这活儿，但不想自己干"** 的人

### ❌ 不适合

- **完全不会用电脑的人** —— 至少要会装软件
- **要绝对安全的人** —— 它会动你电脑的文件，要小心给权限
- **完全不想学** —— 你至少要会"装软件 + 输命令 + 看报错"

## 四、上手 5 步（10 分钟）

### 1. 装 Node.js
去 [nodejs.org](https://nodejs.org/) 下个最新版，一路"下一步"。

### 2. 装 Claude Code
打开终端（Mac）或 PowerShell（Windows），输：

```bash
npm install -g @anthropic-ai/claude-code
```

### 3. 登录

```bash
claude login
```

会跳浏览器，让你登录 Anthropic 账号（**Pro 会员 $20/月**）。

### 4. 进一个项目目录

```bash
mkdir my-first-claude
cd my-first-claude
claude
```

### 5. 开始聊天
终端里直接说：

```
帮我创建一个 hello.md，内容是"你好，我是财务老登"
```

**恭喜你，你已经会用了。**

## 五、5 个常见反例（别这样用）

### ❌ 反例 1：让它"算命"

> "帮我预测下季度营收"

—— 它**不是算命先生**，给不出靠谱预测。

### ❌ 反例 2：让它处理敏感数据

> "这是公司 10000 客户的身份证号，帮我去重"

—— 敏感数据**别上 AI**（不管哪个 AI）。

### ❌ 反例 3：让它"自动决定"

> "帮我想想要不要裁员"

—— 它是工具，**决定权在你**。

### ❌ 反例 4：完全不动手

> "帮我把这个项目做完"

—— 它是**实习生**，不是**替身**。你得盯着。

### ❌ 反例 5：天天追问同一个问题

> "你真的算对了吗？再算一遍"

—— 它会算 100 遍还是那个答案。**你得自己判断**。

## 六、跟 ChatGPT / Claude 网页版的对比

| 我想做的事 | 用啥 |
|---|---|
| 写文案、改稿 | **ChatGPT / Claude 网页版** |
| 问答、查资料 | **ChatGPT / Claude 网页版** |
| 处理本地文件 | **Claude Code** ✓ |
| 跑 Python 脚本 | **Claude Code** ✓ |
| 自动化工作流 | **Claude Code** ✓ |
| 写代码项目 | **Claude Code / Cursor** |
| 移动端 | 只能用 ChatGPT APP |

**简而言之**：

- **ChatGPT** 是**顾问**（出主意）
- **Claude Code** 是**实习生**（干活）

## 七、写在最后

Claude Code 不是银弹。

它：
- 解决不了你"懒"的问题
- 不会让你"不学就会"
- 也不是"装上就自动赚钱"

但它**真能帮你**：
- 每周省几小时
- 让你少做重复事
- 让你把时间花在"真正需要你"的事上

财务老登的 2026 年，**不再是"加班做表"**。
是"告诉 AI 干，我审一遍"。

**这就是我用 Claude Code 5 个月最大的感受。**
